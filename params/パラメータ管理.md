# パラメータ管理

Mission Planner などのGCSツールから書き出した ArduRover パラメータスナップショットを保存します。

## ディレクトリ方針

- `before_fc_replace/` - FC換装前に保存したパラメータ
- `after_fc_replace/` - FC換装直後の初期パラメータ
- `tuned/` - チューニング後に保存したパラメータ

## ファイル名方針

日付と機体状態が分かる名前にします。

```text
YYYY-MM-DD_機体状態_短い説明.param
```

例:

```text
before_fc_replace/20260607_before_fc_replace.param
after_fc_replace/20260608_pixhawk6c_ardurover_initial.param
after_fc_replace/20260608_pixhawk6c_bench_ok.param
tuned/20260608_pixhawk6c_tuned_01.param
```

保存したスナップショットは、あわせて `docs/06_ArduRoverパラメータ.md` に記録します。
