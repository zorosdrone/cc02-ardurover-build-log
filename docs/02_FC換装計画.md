## 交換後のFC

- 型番: Holybro Pixhawk 6C Mini
- 確認した機種バージョン: Pixhawk 6C Mini Model A (Current)
  - 根拠: 上面写真の `AUX5` / `AUX6` / `RC IN` 表記と、Holybro公式資料 `Pixhawk 6C Mini Model A (Current)` のポート図が一致。
  - 撮影写真: `photos/fc_mount/20260608_換装先FC_Pixhawk6Cmini_上面.JPG`
  - 注意: 基板裏面に追加表記はなく、箱もないため、リビジョン印字による追加特定はできない。現時点では外装ポート構成から Model A (Current) と扱う。
- ファームウェアターゲット: ArduPilot Rover / Pixhawk 6C Mini 対応ターゲットを使用予定
- 取り付け向き: 未定。矢印方向を車体前方に合わせる方針。
- 電源モジュール: PM02
  - Pixhawk 6C Miniとセットで購入したパワーモジュールを使用する。
  - 既存Pixhawk 2.4.8Pro側のPower Moduleは流用しない。
  - 換装後は `BATT_*` パラメータを旧FCから丸コピーせず、PM02接続状態で電圧/電流表示を再確認する。
- 必要なケーブル / 変換:
  - 現行M8N GPS UART線とCompass I2C線を、`GPS2` 6ピンへまとめる変換
  - Raspberry Pi / MAVLink線を `TELEM1` へ移す変換
  - LiDAR / RangeFinder線を `TELEM2` へ移す変換
  - RadioLink R8EF SBUS線から `RC IN` への接続確認
  - ステアリングを `MAIN 1`、ESCを `MAIN 3` に接続する前提で出力確認

## 写真確認の扱い

- 裏面に型番、Model、Rev、シリアル等の追加表記はない。
- 箱はないため、箱ラベルからの追加特定はできない。
- 現行FC側の追加接写は、既存写真に必要情報が含まれており、物理的にも難しいため省略する。
- 以後は、保存済み写真と公式ポート表を元に、旧FCからPixhawk 6C Miniへの配線変換表を作る。

## 切り戻しメモ

| 条件 | 対応 | メモ |
| --- | --- | --- |
| RC またはフェイルセーフに重大な問題がある | 走行試験を止め、ベンチ確認に戻す | |
| ステアリングまたはスロットルが逆 | 走行前に出力方向を修正する | |
| 電源が不安定 | 電源モジュール、BEC、配線、GNDを確認する | |
