## 交換後のFC

- 型番: Holybro Pixhawk 6C Mini
- 確認した機種バージョン: Pixhawk 6C Mini Model A (Current)
  - 根拠: 上面写真の `AUX5` / `AUX6` / `RC IN` 表記と、Holybro公式資料 `Pixhawk 6C Mini Model A (Current)` のポート図が一致。
  - 撮影写真: `photos/fc_mount/20260608_換装先FC_Pixhawk6Cmini_上面.JPG`
  - 注意: 基板裏面や箱ラベルのリビジョン印字までは未確認。必要なら裏面写真で再確認する。
- ファームウェアターゲット: ArduPilot Rover / Pixhawk 6C Mini 対応ターゲットを使用予定
- 取り付け向き: 未定。矢印方向を車体前方に合わせる方針。
- 電源モジュール: Pixhawk 6C Mini対応Power Moduleを使用予定。既存Power Module流用時はピン配列確認必須。
- 必要なケーブル / 変換:
  - 現行M8N GPS UART線から `GPS1` への変換
  - 現行M8N Compass I2C線から `I2C` または `GPS1` 統合ポートへの変換
  - Raspberry Pi / テレメトリ線から `TELEM1` または `TELEM2` への変換
  - RadioLink R8EF SBUS線から `RC IN` への接続確認
  - ステアリングを `MAIN 1`、ESCを `MAIN 3` に接続する前提で出力確認

## 切り戻しメモ

| 条件 | 対応 | メモ |
| --- | --- | --- |

| 電源が不安定 | 電源モジュール、BEC、配線、GNDを確認する | |
