# ISDT 608PD LiPo放電・保管手順

作成日: 2026-06-10

## 結論

今の構成では、走行用バッテリー `Zeee 3S 2200mAh 120C LiPo` を `ISDT 608PD` で放電する場合、まずは充電器の `Storage` 相当のタスクで 1セルあたり約 `3.80V` にそろえる運用を優先する。

単純な放電を行う場合は、608PDを外部電源ではなくLiPo側から起動し、USB-C側へ負荷をつないで放電する。ただし、これはUSB-C出力先へ給電する動作なので、目的が「保管電圧へ戻す」だけなら、過放電を避けるためセル電圧を必ず確認しながら行う。

## 今回の機体で使う前提

| 項目 | 内容 |
| --- | --- |
| 充電器 | ISDT 608PD |
| 走行用バッテリー | Zeee 3S 2200mAh 120C LiPo |
| セル数 | 3S |
| 保管電圧の目安 | 3.80V/cell、3S合計で約11.4V |
| 公式マニュアル上のLiPo満充電圧 | 4.20V/cell |
| 公式マニュアル上のLiPo保管電圧 | 3.80V/cell |

## 通常はこう

LiPoは満充電のまま長期保管しない。走行後または充電後にしばらく使わない場合は、各セルを保管電圧付近へ戻す。

3S LiPoなら、目安は次の通り。

| 状態 | 1セルあたり | 3S合計 |
| --- | ---: | ---: |
| 満充電 | 4.20V | 12.60V |
| 保管 | 3.80V | 11.40V |
| 低すぎるため避ける | 3.30V以下付近 | 9.90V以下付近 |

## 今回の充電器ではこう

ISDT 608PD公式マニュアルでは、LiPoのプリセット項目に `Storage 3.80V` が示されている。したがって、充電器メニューに `Storage` または保管電圧へ合わせるタスクが表示される場合は、それを使うのが第一候補。

一方、公式マニュアルの `Discharge Mode` は、608PDをLiPo側から起動し、USB-C出力から外部機器へ給電する図になっている。608PDの仕様ではUSB-C放電出力は最大 `100W / 5A` とされているが、小型LiPoを安全に扱うため、今回の用途では高出力負荷で急いで抜くより、低めの負荷でセル電圧を見ながら進める。

## Charge / Discharge の切り替わり方

608PDでは、`Charge` と `Discharge` は専用スイッチで切り替えるというより、608PDをどちらの電源で起動したかで切り替わる。

| 先に接続して608PDを起動するもの | 608PDの扱い | 画面・動作 |
| --- | --- | --- |
| 上側USB-C入力、または上側XT60 DC入力の外部電源 | 外部電源で動く充電器 | `CHARGE` タスク、下側XT60は `Battery Output` |
| 下側XT60に接続したLiPo | LiPoで動くUSB-C電源 | `USB OUT` / `LOW BATTERY VOLTAGE LIMIT`、下側XT60は `Battery Input` |

実用上は、目的の動作に入らない場合、いったんすべて外して608PDを完全にオフにし、目的の側を先に接続して起動し直す。

## 手順A: Storageタスクで保管電圧にする

1. 作業場所を不燃性の場所にする。
2. 車体から走行用LiPoを外す。
3. バッテリー外観を確認する。
   - 膨らみ、破れ、異臭、発熱、端子の損傷がある場合は作業しない。
4. 608PDへ電源を接続する。
   - USB-C PD入力、またはXT60 DC入力を使う。
5. LiPoのメインコネクタを608PDのバッテリー出力へ接続する。
6. バランスコネクタを608PDのバランスポートへ接続する。
7. バッテリー種別を `LiPo` にする。
8. セル数が `3S` と表示されることを確認する。
9. タスクを `Storage` または保管電圧へ合わせるタスクにする。
10. 終了電圧が `3.80V/cell` 付近であることを確認する。
11. 電流は急がない。
    - 目安は `1.0A` 以下から始める。
    - 発熱や膨らみがあれば即停止する。
12. 開始後、各セル電圧が大きくずれていないか確認する。
13. 完了後、各セルが `3.75V` から `3.85V` 程度に収まっていることを確認する。
14. LiPoを耐火袋または安全な保管場所へ戻す。

## 手順B: Discharge Mode / USB-C出力で放電する

この手順は「608PDをLiPoから給電するUSB-C電源」として使って放電する方法。保管電圧で自動停止する専用手順ではない可能性があるため、セル電圧確認を前提にする。

1. LiPoの現在電圧を確認する。
   - 3S合計で `11.4V` 付近なら、追加放電は不要。
2. 608PDの上側USB-C入力、上側XT60 DC入力には外部電源をつながない。
3. 走行用LiPoを608PDの下側XT60、つまりバッテリー用の `DC input/output` ポートへ接続して608PDを起動する。
4. 可能ならバランスコネクタも接続し、各セル電圧を表示できる状態にする。
5. USB-C出力へ負荷を接続する。
   - 例: USB-C入力対応の小型機器、USB-Cテスター付き負荷、モバイルバッテリーなど。
   - 大電力ノートPC充電のような高負荷は避ける。
6. 608PDのUSB-C出力画面で、低電圧停止しきい値を確認する。
   - 3S LiPoを保管電圧にしたい場合、目標は `3.80V/cell` 付近。
   - 公式マニュアルの例には `LOW BATTERY VOLTAGE LIMIT 3.7V/cell` が出ているが、これは保管電圧より低い。保管目的では `3.8V/cell` 付近で止める。
7. 放電中は数分おきにセル電圧を確認する。
8. どれか1セルでも `3.75V` 付近に近づいたら停止する。
9. 放電後、しばらく置いて電圧が戻るのを待ち、再度セル電圧を確認する。
10. 最終的に各セルが `3.75V` から `3.85V` 程度なら保管する。

## やってはいけないこと

- 車体に接続したまま放電しない。
- バランスコネクタを未確認のまま長時間放置しない。
- 満充電LiPoを無人状態でUSB-C機器へ給電し続けない。
- 3S合計電圧だけを見て、セルごとのばらつきを無視しない。
- 熱い、膨らむ、異臭がする、電圧が急落する状態で続行しない。

## 実機確認項目

次回作業時に、608PD実機画面で以下を確認して追記する。

- [ ] `Storage` タスクが表示されるか。
- [ ] `Discharge` タスクがタスク選択画面に表示されるか。
- [ ] USB-C出力時の低電圧停止しきい値を `3.8V/cell` に設定できるか。
- [ ] バランスコネクタ接続時に3セル個別電圧が表示されるか。
- [ ] 終了後の各セル電圧。
