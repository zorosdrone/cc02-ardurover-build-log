## 記録方針

現在のチューニング前ベースライン:


## 重点パラメータ

### 安全 / 入口条件

| パラメータ | 現在値 | 次の判断 |
| --- | --- | --- |
| `COMPASS_ENABLE` | `0` | 屋外試験前に`1`へ戻す |
| `BATT_LOW_VOLT` / `BATT_CRT_VOLT` | `0` / `0` | 低電圧時の中止基準を決める |
| `BATT_FS_LOW_ACT` / `BATT_FS_CRT_ACT` | `0` / `0` | 初期試験は手動監視。運用前に再検討 |
| `MODE_CH` | `5` | 実スイッチ位置を記録 |
| `MODE1/2/5/6` | `4` | Hold。重複位置をAcro一時割当に使える |
| `MODE3/4` | `0` | Manual。退避先として残す |
| `RC7_OPTION` | `153` | 意味が確定するまで変更しない |

### Speed / Throttle

| パラメータ | 現在値 | 次の判断 |
| --- | --- | --- |
| `CRUISE_SPEED` | `2` | 初回屋外で速ければ下げる |
| `CRUISE_THROTTLE` | `50` | 実走行で再学習または維持 |
| `ATC_SPEED_P` / `I` / `D` / `FF` | `0.2` / `0.2` / `0` / `0` | まずログで追従確認 |
| `ATC_ACCEL_MAX` / `ATC_DECEL_MAX` | `1` / `0` | 発進 / 停止距離で判断 |

### Turn Rate

| パラメータ | 現在値 | 次の判断 |
| --- | --- | --- |
| `ACRO_TURN_RATE` | `180` | 実測最大旋回レートより少し低く設定 |
| `ATC_STR_RAT_FF` / `P` / `I` / `D` | `0.2` / `0.2` / `0.2` / `0` | まずログ取得。必要時のみ変更 |
| `ATC_STR_RAT_MAX` | `120` | `ACRO_TURN_RATE` と整合確認 |
| `ATC_TURN_MAX_G` | `0.6` | 横滑り / 転倒リスクで判断 |
