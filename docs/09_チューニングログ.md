## 2026-06-12 LiDAR Proximity静置切り分け

詳細記録:

```text
logs/test_runs/20260612_02_lidar_proximity_static_check.md
```

追加確認:

```text
PRX1_TYPE = 0
→ RangeFinder距離表示あり

PRX1_TYPE = 4
→ 距離表示なし
```

判断:

- Acroで2m停止しなかった直接原因は、実走時点で `PRX1_TYPE=0` だったことが大きい。
- ただし、`PRX1_TYPE=4` にすると距離表示が消えるため、そのまま実走再試験には進まない。
- `PRX1_TYPE=4` でRangeFinder表示が消えても、Proximity ViewerまたはDataFlashの `PRX` に前方障害物が出るかを確認する。
- Proximity Viewer / `PRX` のどちらにも出ない場合は、`PRX1_TYPE=0` に戻し、RangeFinder単体またはGCS側Auto-stop方針へ戻す。

次の最優先:

```text
PRX1_TYPE=4 の状態で、Proximity ViewerまたはPRXログに前方障害物が出るか確認する。
```
