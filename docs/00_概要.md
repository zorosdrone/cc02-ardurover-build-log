## 障害物回避機能開発

CC-02 Roverは、前方TF-LunaとArduPilot標準のSimple Object Avoidanceにより、Acro低速およびGuidedで障害物前停止まで確認済みです。この既存設定を通常運用の安全な基準として残し、Luaによる追加制御は別パラメータで段階的に検証します。

開発の主目的は、前方LiDARの距離をLuaで読み取り、警戒距離で減速、停止距離で停止、必要に応じて限定的な後退・固定方向旋回・前方再確認を行う状態機械を作ることです。前方センサーは1個だけなので、最初から左右の空き方向を選ぶ万能な自動迂回は目標にせず、「前方障害物を確実に検出して安全側へ止める」ことを優先します。

実装は、実機ファームウェアに合わせたArduRover 4.6.3のSITLで、内蔵ポストと前方1点Rangefinderによる距離取得、Lua状態機械、仮想ポスト表示を先に確認し、その後に実機TF-Lunaへ移します。最新ArduPilotソースを使うメンバー向けの差分は手順内に残し、SITL用Rangefinder設定と実機TF-Luna設定は別物として扱います。

関連資料は [Lua障害物回避プロジェクト概要](13_Lua障害物回避/README.md)、[Rover SITL前方Rangefinder / 標準OA / Lua設定手順](13_Lua障害物回避/01_RoverSITL前方Rangefinder設定手順.md)、[LuaとC++独自モードの実装判断](13_Lua障害物回避/03_LuaとC++の実装判断.md)、[仮想ポストKML表示補助](13_Lua障害物回避/補助機能/10_MP_仮想ポストKML表示補助.md) にまとめます。
