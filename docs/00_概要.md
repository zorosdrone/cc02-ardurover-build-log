## 障害物回避機能開発

CC-02 Roverは、前方TF-LunaとArduPilot標準のSimple Object Avoidanceにより、Acro低速およびGuidedで障害物前停止まで確認済みです。この既存設定を通常運用の安全な基準として残し、Luaによる追加制御は別パラメータで段階的に検証します。

開発の主目的は、前方LiDARの距離をLuaで読み取り、警戒距離で減速、停止距離で停止、必要に応じて限定的な後退・固定方向旋回・前方再確認を行う状態機械を作ることです。前方センサーは1個だけなので、最初から左右の空き方向を選ぶ万能な自動迂回は目標にせず、「前方障害物を確実に検出して安全側へ止める」ことを優先します。

実装は、SITLで距離取得、Lua状態機械、Guided Target復帰を確認した後、ArduRover 4.6.3実機へ移行しました。実機v9.1で直進後退、前進旋回、前方再確認、Target復帰を確認し、現行は停止`1.0 m`、走行`0.50 m/s`、後退`2.25秒`、前進旋回`6.0秒`を基準に限定試験を続けています。SITL用Rangefinder設定と実機TF-Luna設定は引き続き別物として扱います。

関連資料は [Lua障害物回避プロジェクト概要](../projects/03_Lua障害物回避/README.md)、[Lua障害物回避 実機テスト手順](../projects/03_Lua障害物回避/07_実機テスト手順.md)、[SITLから実機移行で起きた問題と再発防止](../projects/03_Lua障害物回避/08_SITLから実機移行で起きた問題と再発防止.md) にまとめます。
