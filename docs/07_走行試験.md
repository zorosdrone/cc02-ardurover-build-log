## 屋外前チェックリスト

### 機体 / 電源

- [ ] 走行用LiPoを物理的にすぐ外せる
- [ ] ESC / モーター電源を切る手順を操作者が理解している
- [ ] タイヤを浮かせて、Arm / Disarm / スロットル中立 / 前進 / 後退を確認した
- [ ] `MOT_SAFE_DISARM=1` でDISARM時に駆動出力が止まることを確認した
- [ ] PM02電圧表示をテスター実測と比較した
- [ ] Battery low / critical の警告値、または短時間試験中止基準を決めた

### RC / Mode

- [ ] ステアリングが `RC1`
- [ ] 前進 / 後退が `RC2`
- [ ] `MODE_CH=5` の実スイッチ位置を確認した
- [ ] `MODE1/2/5/6=Hold`、`MODE3/4=Manual` の実位置を記録した
- [ ] Manual と Hold の退避先を残した
- [ ] Acroを一時割当する場合、重複Hold位置だけを使った
- [ ] `RC7_OPTION=153` の実機スイッチと機能を確認した
- [x] RCフェイルセーフをタイヤ浮かせ状態で確認した

### GPS / Compass / EKF

- [ ] 屋内テスト用の `COMPASS_ENABLE=0` を、屋外試験前に `1`へ戻した
- [ ] GPS/Compassマスト長変更後の実測長さ、固定状態、向きを記録した
- [ ] Compass Calibration前に `params/tuned/20260610_before_compass_mast_cal.param` を保存した
- [ ] M10 GPS / Compassを実搭載位置で固定した
- [ ] Compass Calibrationを変更後マスト長・屋外試験前状態で実施した
- [ ] Compass Calibration後に `params/tuned/20260610_after_compass_mast_cal.param` を保存した
- [ ] GPS `3D Fix`
- [ ] PreArm / EKF / Compass / GPS エラーなし
- [ ] Home位置が妥当

### Sensor / GCS

- [ ] LiDAR / RangeFinder値がMission Plannerで見える
- [ ] rover-gcs側で距離値が更新される
- [ ] `RNGFND1_MAX_CM=700` のまま使うか、`200`等へ戻すか判断した
- [ ] Auto-stop閾値 `40 / 60 / 80 / 100cm` のどれを使うか記録した
- [ ] Raspberry Pi / MAVLink通信が安定している
- [ ] GCS操作中でもプロポとMission Plannerで止められる

## 次回の推奨試験順

1. タイヤ浮かせ: Manual / Hold / Disarm / RC FS（確認済み）
2. 屋外静置: Compass / GPS / EKF / Battery / LiDAR確認
3. Manual 低速: 1 m前進、停止、後退、左右ステア
4. Manual 低速: 10 m程度の直進と停止距離確認
5. Hold切替: 走行中にHoldへ切り替え、停止挙動を確認
6. Acro一時割当: タイヤ浮かせでモード表示確認
7. Acro低速: Speed / Turn Rateログ取得のみ。値変更はログ確認後
8. Guided / Auto / RTL: 上記が通ってから低速・短距離で実施
