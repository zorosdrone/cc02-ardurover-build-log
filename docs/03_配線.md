## 写真から確認できること

- 現行FCは Pixhawk 2.4.8Pro / Pixhawk Pro 系の上面ポート構成。
- `POWER`、`TELEM`系、`GPS`、`I2C`、`SWITCH`、`BUZZER` 付近に接続がある。
- `MAIN OUT 1` にステアリングサーボ、`MAIN OUT 3` にESC / スロットルが接続されている。
- 受信機は RadioLink R8EF V1.6 で、`S.BUS / CH1` に接続されている。
- コンパニオンコンピュータ系は現行TELEM2接続。6C Mini換装後は`TELEM1`へ移す候補。
- M8N GPSはGPSポート、Compass系はI2Cポートへ分かれて接続されている。
- LiDAR / RangeFinderは現行パラメータ上 `SERIAL4_PROTOCOL=9`, `SERIAL4_BAUD=115` のため、現行FCのSERIAL4系に接続されている扱い。
- Pixhawk 6C miniへ換装する前に、コネクタが刺さるかではなく、各信号のピン順を実測・目視で確認する必要がある。

## 換装時の写真確認方針

- 裏面に型番、Model、Rev、シリアル等の追加表記はない。
- 箱はないため、箱ラベルによる追加確認はしない。
- 現行FC側の追加接写は、既存写真に含まれる情報で進める。
- 物理的に撮影が難しい箇所は、無理に撮影せず、抜線時の実機目視で補足する。

| 現行Pixhawk 2.4.8Pro側 | 現行用途 | Pixhawk 6C Mini側候補 | 状態 | メモ |

## GPS2 6ピン変換メモ

現行M8Nの2股配線を、Pixhawk 6C Miniの`GPS2` 6ピンへまとめる。

| GPS2側信号 | 接続する現行M8N側 | 注意 |
| --- | --- | --- |
| `VCC` | GPS UART系またはCompass I2C系の5V | 5Vは共通化する。重複給電にならないよう配線を整理する。 |
| `UART TX` | M8N GPS側 `RX` | FCからGPSへ送る線。TX/RXは交差接続。 |
| `UART RX` | M8N GPS側 `TX` | GPSからFCへ送る線。TX/RXは交差接続。 |
| `I2C SCL` | M8N Compass側 `SCL` | SCL同士を接続。 |
| `I2C SDA` | M8N Compass側 `SDA` | SDA同士を接続。 |
| `GND` | GPS UART系またはCompass I2C系のGND | GNDは共通化する。 |

`GPS2` 6ピンへまとめられない場合だけ、`GPS1`または独立`I2C`ポートを予備候補として使う。

## LiDAR / RangeFinder移行メモ

現行はLiDAR / RangeFinderが`SERIAL4/5`系に接続されている。パラメータ上は以下を現行値として扱う。

| パラメータ | 現行値 | 意味 |
| --- | --- | --- |
| `SERIAL4_PROTOCOL` | `9` | RangeFinder |
| `SERIAL4_BAUD` | `115` | 115200bps |
| `SERIAL5_PROTOCOL` | `-1` | 無効 |
| `RNGFND1_TYPE` | `20` | TF-Luna / RangeFinder系として扱う |

Pixhawk 6C MiniではArduPilot上の`SERIAL4`が物理`GPS2`に対応する。今回は`GPS2`を現行M8N GPS + Compass用に使うため、LiDARへ`SERIAL4`設定を丸コピーしない。

推奨割り当て:

| 機器 | 6C Mini物理ポート | ArduPilot Serial候補 | 設定候補 | メモ |
| --- | --- | --- | --- | --- |
| Raspberry Pi / MAVLink | `TELEM1` | `SERIAL1` | `SERIAL1_PROTOCOL=2`, `SERIAL1_BAUD=921` | 現行TELEM2相当のMAVLink接続をTELEM1へ移す候補。 |
| LiDAR / RangeFinder | `TELEM2` | `SERIAL2` | `SERIAL2_PROTOCOL=9`, `SERIAL2_BAUD=115` | `TELEM2`でよい。Raspberry Piと同じポートには接続しない。 |
| M8N GPS + Compass | `GPS2` | `SERIAL4` | `SERIAL4_PROTOCOL=5` | `GPS2` 6ピンへGPS UART + I2Cをまとめる。 |

`TELEM2`をRaspberry Piで使い続ける場合は、LiDARを`TELEM1`へ接続して、`SERIAL1_PROTOCOL=9`、`SERIAL1_BAUD=115`にする。どちらでもよいが、1つのUARTポートにRaspberry PiとLiDARを同時接続しない。

LiDAR UARTの基本配線:

```text
6C Mini TELEMx TX -> LiDAR RX
6C Mini TELEMx RX -> LiDAR TX
6C Mini TELEMx GND -> LiDAR GND
5V給電はLiDARの仕様と消費電流を確認してから接続する
```

## 次にやること

1. 現行配線の一時ラベル貼りは省略する。
   - 代わりに、写真、ポート名、線色、実機目視で記録する。
   - 追加接写は省略し、既存写真と抜線時の目視で補足する。
2. `MAIN OUT` の確定情報を換装表に反映する。
   - ステアリングサーボ: `MAIN OUT 1`
   - ESC / スロットル: `MAIN OUT 3`
3. 現行M8N GPSの2股を分けて確認する。
   - GPS UART: `5V / GND / TX / RX`
   - Compass I2C: `5V / GND / SDA / SCL`
   - 6C Mini側は`GPS2` 6ピンへまとめる方針。
   - `GPS2`側信号: `VCC / UART TX / UART RX / I2C SCL / I2C SDA / GND`
4. TELEM系の移行先を確定する。
   - 推奨: Raspberry Pi / MAVLinkを`TELEM1`へ移す。
   - 推奨: LiDAR / RangeFinderを`TELEM2`へ移す。
   - 理由: `GPS2`はM8N GPS + Compass用に使うため、6C Mini側の`SERIAL4`はLiDARに使わない。
5. Pixhawk 6C Mini側のポート表と照合し、変換表を作る。
   - 旧Pixhawk 2.4.8Proポート
   - 信号名
   - 線色
   - Pixhawk 6C Mini側ポート
   - 6C Mini側ピン番号
   - PM02はPixhawk 6C Miniセット付属品を使用するため、旧Power Moduleの流用変換は行わない。
6. Safety Button、Buzzer、USBは削除予定として扱う。
   - Safety Button: 6C Miniへ移植しない。
   - Buzzer: 6C Miniへ移植しない。
   - USB: 常用配線から外す。設定・緊急作業時のみ必要に応じて使う。
7. Safety Button / Buzzer削除後の代替安全策を確定する。
   - ESC/モーター電源の物理カット
   - RCスロットルカット
   - `ARMING_CHECK` の安全側設定
   - GCS/PC側の警告表示と音通知
8. 追加撮影は省略し、配線変換表の作成に進む。
   - 現行FC側の近接写真は既存写真で代替する。
   - 物理的に見えない箇所は、抜線時に線色と行き先を目視で補足する。
   - 次の作業は、旧FCポートとPixhawk 6C Miniポートの対応表作成。
