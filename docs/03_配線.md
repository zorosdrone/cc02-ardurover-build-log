## 写真から確認できること

- 現行FCは Pixhawk 2.4.8Pro / Pixhawk Pro 系の上面ポート構成。
- `POWER`、`TELEM`系、`GPS`、`I2C`、`SWITCH`、`BUZZER` 付近に接続がある。
- `MAIN OUT 1` にステアリングサーボ、`MAIN OUT 3` にESC / スロットルが接続されている。
- 受信機は RadioLink R8EF V1.6 で、`S.BUS / CH1` に接続されている。
- コンパニオンコンピュータ系は TELEM2 接続として扱う。
- M8N GPSはGPSポート、Compass系はI2Cポートへ分かれて接続されている。
- Pixhawk 6C miniへ換装する前に、コネクタが刺さるかではなく、各信号のピン順を実測・目視で確認する必要がある。

## 次にやること

1. 現行配線の一時ラベル貼りは省略する。
   - 代わりに、写真、ポート名、線色、実機目視で記録する。
   - 抜線前に近接写真を追加して、戻せるだけの情報を残す。
2. `MAIN OUT` の確定情報を換装表に反映する。
   - ステアリングサーボ: `MAIN OUT 1`
   - ESC / スロットル: `MAIN OUT 3`
3. 現行M8N GPSの2股を分けて確認する。
   - GPS UART: `5V / GND / TX / RX`
   - Compass I2C: `5V / GND / SDA / SCL`
4. TELEM2接続をPixhawk 6C mini側のどのTELEMポートへ移すか決める。
   - 現行: Pixhawk 2.4.8Pro `TELEM2`
   - 換装先候補: Pixhawk 6C mini `TELEM1` または `TELEM2`
   - `SERIALx_PROTOCOL` / `SERIALx_BAUD` との対応を確認する。
5. Pixhawk 6C mini側のポート表と照合し、変換表を作る。
   - 旧Pixhawk 2.4.8Proポート
   - 信号名
   - 線色
   - Pixhawk 6C mini側ポート
   - 6C mini側ピン番号
6. Safety Button、Buzzer、USBは削除予定として扱う。
   - Safety Button: 6C miniへ移植しない。
   - Buzzer: 6C miniへ移植しない。
   - USB: 常用配線から外す。設定・緊急作業時のみ必要に応じて使う。
7. Safety Button / Buzzer削除後の代替安全策を確定する。
   - ESC/モーター電源の物理カット
   - RCスロットルカット
   - `ARMING_CHECK` の安全側設定
   - GCS/PC側の警告表示と音通知
8. 配線を抜く前に、必要なら追加撮影する。
   - POWERポート近接
   - MAIN OUT 1-3近接
   - GPS/I2Cのピン番号が読める角度
   - TELEM2のピン番号が読める角度
