## 記録方針

## 信号方向チェック

- [ ] ステアリング出力が意図した方向に動く
- [ ] スロットル出力が意図した方向に動く
- [ ] RC入力チャンネルが正しく割り当てられている
- [ ] モードスイッチ位置とモードが一致している
- [ ] タイヤを浮かせた状態でフェイルセーフを確認した
