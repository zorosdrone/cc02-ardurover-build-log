# 現在状況

## スナップショット

- 記録日: 2026-06-12
- 現在パラメータ: `params/tuned/20260612_01_after_lidar_simple_avoid_acro_margin1_stop_check.param`
- 機体状態: Pixhawk 6C MiniへFC換装済み。屋内 Manual 低速走行まで確認済み。屋外チューニング前。
- ベース車両: タミヤ CC-02
- フライトコントローラ: Holybro Pixhawk 6C Mini Model A (Current)
- Firmware target: `Pixhawk6C`
- Vehicle firmware: ArduRover
- 受信機 / 送信機: RadioLink R8EF / T8FB系。RC INで認識済み。
- ESC: ブラシモーター用ESC。前進 / 後退 / 中立を Manual で確認済み。
- ステアリングサーボ: DS3218 20kg
- 走行用バッテリー: Zeee 3S 2200mAh 120C
- 電源モジュール: PM02
- GPS / Compass: Rover向けに追加購入したM10 GPSをGPSモジュールとして採用。Pixhawk 6C Mini `GPS1` 10ピンへ接続し、GPS `3D Fix` と Compass認識は確認済み。
- 距離センサー: Benewake TF-Luna。`TELEM2`で距離確認済み。
- Raspberry Pi / MAVLink: `TELEM1`で通信確認済み。
- GCS: `rover-gcs` は別リポジトリで管理。こちらでは実機構成、パラメータ、走行試験、チューニングを記録する。

## 現在の作業フェーズ

```text
FC換装済み
  -> 屋内 Manual 低速走行済み
  -> 屋外前安全確認済みの項目あり
  -> Acro割当 / Acro低速確認済み
  -> LiDAR室内確認済み
  -> QuickTune前安全確認中
  -> Auto / Guided / RTL は未実施
```

現時点での最優先は、PIDやNavigation調整ではなく、屋外試験に入るための安全入口確認である。

## 既知の注意点

| 日付 | 注意点 | 影響 | 対応 |
| --- | --- | --- | --- |
| 2026-06-09 | `COMPASS_ENABLE=0` | 室内Manual用の一時設定。自律系では方位/EKF評価ができない | 屋外前に `1`へ戻す |
| 2026-06-10 | GPS/Compassマスト長変更 | Compassの磁気環境と搭載位置条件が変わる | `COMPASS_ENABLE=1`へ戻してCompass Calibrationをやり直す |
| 2026-06-10 | `BATT_VOLT_MULT=18.62` | 過去文書の `18.182` と差分あり | 走行前に実測で採用値を確定 |
| 2026-06-10 | Battery failsafe値が0 | 低電圧時に自動動作しない | 初期は短時間・手動監視。運用前に値を決める |
| 2026-06-10 | Acro未割当 | Speed / Turn Rate tuningに入れない | 2026-06-11に`MODE4=Acro`として対応済み |
| 2026-06-10 | `CRUISE_SPEED=2`, `WP_SPEED=2` | 初回屋外では速い可能性 | 低速Manual / Acroで停止余裕を確認してから使う |
| 2026-06-10 | `RNGFND1_MAX_CM=700` | 過去候補 `200` と差分あり | Auto-stop最大閾値、実測、GCS表示で決める |
| 2026-06-09 | M8N GPS2流用は中止 | 旧GPS/Compassの配線課題が残り、Rover向けにM10 GPSを追加購入した | M10 GPSを継続使用 |
| 2026-06-12 | M10 GPSを採用 | Rover向けに追加購入したM10 GPSで、GPS `3D Fix` とCompass認識を確認済み | `GPS1` 10ピン接続のM10 GPSをGPSモジュールとして運用 |
| 2026-06-12 | LiDAR室内確認完了 | RangeFinder / Simple Object Avoidanceの室内確認は完了扱い | QuickTune優先。Object Avoidanceの深掘りは後回し |
