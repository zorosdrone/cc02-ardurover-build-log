## 起動・停止の現行手順

### 起動

1. プロポの電源を入れる。
2. Rover の制御系電源を入れる。
3. Pixhawk の起動音、LED、ブザーを確認する。
4. Raspberry Pi / Rpanion を使う場合は、Pi の起動完了まで待つ。
5. 通信確認が終わるまで走行用LiPoは接続しない。
6. Mission Planner または GCSで Heartbeat、Mode、Battery、GPS、RC入力を確認する。
7. タイヤを浮かせた状態で ARM / 出力確認を行う。

### 異常時停止

1. プロポのスロットルを中立にする。
2. Mission Planner または GCS で `DISARM` する。
3. 走行用LiPoを外す。

### 終了

1. `DISARM` する。
2. 走行用LiPoを外す。
3. 制御系電源を切る。
4. 送信機を切る。
