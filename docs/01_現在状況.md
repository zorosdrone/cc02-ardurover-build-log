# 現在状況

## スナップショット

- 記録日: 2026-06-12
- 現在パラメータ: `params/tuned/20260610_before_tune.param`
- 機体状態: Pixhawk 6C MiniへFC換装済み。屋内 Manual 低速走行まで確認済み。屋外チューニング前。
- ベース車両: タミヤ CC-02
- フライトコントローラ: Holybro Pixhawk 6C Mini Model A (Current)
- Firmware target: `Pixhawk6C`
- Vehicle firmware: ArduRover
- 受信機 / 送信機: RadioLink R8EF / T8FB系。RC INで認識済み。
- ESC: ブラシモーター用ESC。前進 / 後退 / 中立を Manual で確認済み。
- ステアリングサーボ: DS3218 20kg
- 走行用バッテリー: Zeee 3S 2200mAh 120C
- 電源モジュール: PM02
- GPS / Compass: 購入済みのM10 GPSをGPSモジュールとして採用。Pixhawk 6C Mini `GPS1` 10ピンへ接続し、GPS `3D Fix` と Compass認識は確認済み。
- 距離センサー: Benewake TF-Luna。`TELEM2`で距離確認済み。
- Raspberry Pi / MAVLink: `TELEM1`で通信確認済み。
- GCS: `rover-gcs` は別リポジトリで管理。こちらでは実機構成、パラメータ、走行試験、チューニングを記録する。

## 現在の作業フェーズ

```text
FC換装済み
  -> 屋内 Manual 低速走行済み
  -> 屋外前安全確認中
  -> Acro / Speed / Turn Rate チューニング前
  -> Auto / Guided / RTL は未実施
```

現時点での最優先は、PIDやNavigation調整ではなく、屋外試験に入るための安全入口確認である。
