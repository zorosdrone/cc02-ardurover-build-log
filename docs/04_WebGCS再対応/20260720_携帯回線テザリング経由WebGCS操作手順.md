# 携帯回線テザリング経由 WebGCS操作手順

## 目的

ローバー搭載スマートフォンの携帯回線を使い、Raspberry Pi Zero 2 W、Tailscale、クラウド上のWebGCSを経由して遠隔操作する。

```text
スマートフォン（LTE／テザリング）
  → Raspberry Pi Zero 2 W（Rpanion）
  → Tailscale・UDP 14552
  → DigitalOcean WebGCS
  → HTTPS・操作端末ブラウザ
```

過去資料にはLTE利用と各接続設定は記録されているが、テザリング開始からの一連の手順はなかったため、本書で再構成する。

## 事前条件

- Rover、Pixhawk、Raspberry Pi Zero 2 W、スマートフォンの電源が確保されている。
- PiとDigitalOceanサーバーが同じTailnetに登録されている。
- DigitalOcean上でWebGCSを起動できる。
- 初回確認はDISARMし、タイヤを浮かせて行う。

## 1. 携帯回線とPiの接続

1. スマートフォンでモバイルデータ通信を有効にする。
2. Wi-Fiテザリングを有効にする。
3. PiをスマートフォンのテザリングWi-Fiへ接続する。
4. PiでインターネットとTailscaleの状態を確認する。

```bash
ping -c 3 8.8.8.8
ping -c 3 google.com
tailscale status
tailscale ip -4
```

## 2. RpanionのMAVLink転送設定

Rpanionの`Flight Controller` → `Endpoints`でWebGCS向け出力を設定する。

```text
Type: UDP Client
Address: <DigitalOceanサーバーのTailscale IP>
Port: 14552
```

Mission Plannerにも同時送信する場合は、次も追加する。

```text
udp:<Mission Planner PCのTailscale IP>:14550
```

## 3. DigitalOcean WebGCSの起動

サーバーへSSH接続し、WebGCSを起動する。

```bash
cd ~/rover-gcs
docker compose -f docker-compose.prod.yml up -d
docker ps
```

DigitalOcean側のTailscale状態も確認する。

```bash
tailscale status
tailscale ip -4
```

## 4. MAVLink接続確認

WebGCSバックエンドのログで、次の流れを確認する。

```text
[backend] Waiting for MAVLink heartbeat on udp:0.0.0.0:14552...
[backend] MAVLink heartbeat received
```

接続できない場合は次を確認する。

- Rpanionの送信先がDigitalOcean側のTailscale IPになっている。
- ポートがUDP `14552`になっている。
- PiとDigitalOceanがTailscaleでオンラインになっている。
- FirewallでUDP `14552`が遮断されていない。

## 5. ブラウザからの操作確認

1. 操作端末からWebGCSのHTTPS URLを開く。
2. ログインする。
3. `DISARMED`であることを確認する。
4. Heartbeat、Mode、Battery、GPS、RC_CHANNELSが更新されることを確認する。
5. タイヤを浮かせた状態でWebGCSからARM、STOP、DISARMを確認する。
6. Web操縦を行う場合だけ`TX`を有効にする。

## 6. プロポへ操作を戻す

WebGCSのTXが有効な間は、MAVLink RC OverrideがプロポのRC1・RC3を上書きする。

1. Webジョイスティックを中立にする。
2. `TX: Off`にする。
3. WebGCSの操作部には触れない。
4. `RC_OVERRIDE_TIME=3`秒以上待つ。
5. Mission PlannerでプロポのRC1・RC3入力が反映されることを確認する。

詳細は[WebGCS TXによるプロポ入力上書き](20260720_WebGCS_TXによるプロポ入力上書き.md)を参照する。

## 7. 映像配信を使う場合

ローバー搭載スマートフォンで、WebGCSから取得したVDO.Ninja配信用URLを開いて配信を開始する。

```text
https://<WebサーバーIPまたはドメイン>/vdo/index.html?push=<ViewID>
```

カメラ利用にはHTTPSが必要。映像はVDO.Ninja経由、操縦・テレメトリはTailscale／MAVLink経由であり、通信経路が異なる。

## 注意事項

- この手順はDigitalOcean Dropletが存在し、Tailscaleへログイン済みであることを前提とする。
- Droplet、Public IP、DNS、Tailscale IPの現在値は運用前に確認する。
- 携帯回線の遅延・切断を前提に、プロポ、STOP、DISARM、走行用LiPo切断を停止手段として確保する。
- 地上走行は、通信確認とタイヤ浮かせ試験がすべて完了してから行う。
