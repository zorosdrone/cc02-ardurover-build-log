# WebGCS TXによるプロポ入力上書き

## 症状

- Mission PlannerのRadio Calibrationで、右スティックを動かしてもRC1・RC3が反映されない。
- WebGCSを`TX: Off`にすると、プロポのRC1・RC3入力が反映される。

## 原因

WebGCSのTXが有効な間、RC1（ステアリング）とRC3（スロットル）へMAVLinkのRC Overrideを周期送信していた。
Webジョイスティックが中立でも1500を送るため、物理プロポの入力が上書きされていた。

`RCMAP`やT8FBのチャンネル設定、右スティックの故障が原因ではなかった。

## プロポへ戻す手順

1. Webジョイスティックを中立にする。
2. WebGCSを`TX: Off`にする。
3. WebGCSのジョイスティック、スライダー、STOPには触れない。
4. `RC_OVERRIDE_TIME=3`秒以上待つ。
5. Mission PlannerでRC1・RC3がプロポ操作に追従することを確認する。

## 注意点

現在の`TX: Off`は周期送信を止めるだけで、RC Overrideを即時解除していない。
Offの状態でもWeb操作を行うと単発のOverrideが送られ、約3秒間プロポ入力が上書きされる可能性がある。

今後、`TX: Off`への切替時に`RELEASE_OVERRIDE`を送って即時にプロポへ戻す実装を検討する。
