# 2026-06-13 RTL / SmartRTL中 LiDAR障害物認識ログ確認

## 対象ログ

```text
logs/test_runs/20260613_03a_rtl_smartrtl_LiDAR_stop_check.bin
```

## 目的

RTL / SmartRTL中に障害物を置いた場合、LiDAR / Proximityが障害物を認識しているかを確認する。

## ログ内メッセージ

| メッセージ | 件数 | 意味 |
| --- | ---: | --- |
| `RFND` | 29534 | RangeFinder距離 |
| `PRX` | 1747 | Proximity化された障害物距離 |
| `THR` | 5906 | 目標速度、実速度、スロットル出力 |
| `RCOU` | 5906 | サーボ / ESC出力 |
| `MODE` | 30 | モード遷移 |

## モード区間での確認

RTL / SmartRTL中にも `PRX` が記録されており、障害物はある程度認識されている。

代表例:

| 時刻 | Mode | `RFND.Dist` | `PRX.D0` | `PRX.CDis` | `THR.DesSpeed` | `RCOU.C3` | 判断 |
| ---: | --- | ---: | ---: | ---: | ---: | ---: | --- |
| 103.51s | RTL | 0.24m | 2.17m | 0.24m | 0.92m/s | 1602 | 近距離障害物を認識。ただし前進出力は残る |
| 132.71s | RTL | 0.21m | 0.51m | 0.21m | 0.54m/s | 1578 | 前方/最近接とも近距離を認識。減速気味だが停止ではない |
| 334.91s | SmartRTL | 0.19m | 0.49m | 0.20m | 0.26m/s | 1549 | SmartRTL中に近距離認識。速度指令は下がるが完全停止ではない |
| 462.41s | SmartRTL | 0.24m | 0.93m | 0.24m | 0.96m/s | 1610 | 近距離認識はあるが前進指令が残る |
| 567.91s | RTL | 0.57m | 0.75m | 0.57m | 0.00m/s | 1500 | 近距離認識後に停止状態 |

## 判断

- RTL / SmartRTL中にもLiDAR / Proximityはある程度機能している。
- `RFND.Dist` と `PRX.CDis` は、障害物近接時に0.2m級まで低下している。
- `PRX.D0` と `PRX.CDis` が一致しない場面があり、正面ではなく斜め・最近接方向として検出されている可能性がある。
- 近距離障害物を認識しても、`THR.DesSpeed` や `RCOU.C3` が必ず停止側へ落ちるわけではない。
- RTL / SmartRTLのどちらも、近距離障害物を認識しても停止精度は同程度で、停止保証まではできていない。
- SmartRTL中の障害物接触とタイヤ空転は、ログ上の近距離認識と矛盾しない。

## 運用判断

- RTL / SmartRTL中のLiDAR認識は「補助的に見えている」扱い。
- RTL / SmartRTLは帰還・経路復帰用として扱い、障害物停止手段としては採用しない。
- 障害物がある環境ではRTL / SmartRTLに任せず、Manual / Hold / Disarmへ即退避する。
- 障害物前停止の主な確認対象は、引き続き `OA_TYPE=0` のSimple Object Avoidanceを使った低速Acro確認とする。
