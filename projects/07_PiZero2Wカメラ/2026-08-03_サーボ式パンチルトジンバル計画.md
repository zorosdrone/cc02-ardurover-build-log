# Pi Zero 2 Wカメラ用サーボ式パン・チルトジンバル計画

## 結論

OV5647カメラのパン・チルト制御は、Raspberry PiのGPIOではなくPixhawk 6C MiniのPWM出力を使う。Mission PlannerからMAVLinkでPixhawkのMount機能を操作し、Pixhawkが2個のサーボへPWMを出力する。

本文書は計画段階であり、配線やArduPilotパラメータはまだ変更していない。サーボの型番、定格電圧、停止電流、機構の可動範囲を確定してから実装する。

## 1. システム構成

映像とジンバル制御は別経路とする。

```text
映像経路
OV5647カメラ
  └─ Raspberry Pi Zero 2 W / Rpanion
       └─ RTSP
            └─ Mission Planner HUDまたはGimbal Video

制御経路
Mission Planner
  └─ MAVLink
       └─ Rpanion / TELEM1
            └─ Pixhawk 6C Mini
                 ├─ MAIN 5 PWM → Panサーボ
                 └─ MAIN 6 PWM → Tiltサーボ
```

Raspberry Piはカメラ取得とRTSP配信を担当し、サーボ制御は担当しない。

## 2. Pixhawk出力の割り当て案

### 現在の機体状態

2026-06-13の保存パラメータと配線記録では、次の割り当てになっている。

| Pixhawk出力 | ArduPilot出力 | 現在値 | 用途 |
| --- | --- | --- | --- |
| `MAIN 1` | `SERVO1` | `SERVO1_FUNCTION=26` | Ground Steering |
| `MAIN 3` | `SERVO3` | `SERVO3_FUNCTION=70` | Throttle / ESC |
| `MAIN 5` | `SERVO5` | `SERVO5_FUNCTION=0` | 未使用 |
| `MAIN 6` | `SERVO6` | `SERVO6_FUNCTION=0` | 未使用 |
| `AUX 1`～`AUX 4` | `SERVO9`～`SERVO12` | 左右HC-SR04用として計画 | Trigger / Echo |

### ジンバル用候補

| 軸 | 接続候補 | 出力機能候補 |
| --- | --- | --- |
| Pan / Yaw | Pixhawk `MAIN 5` | `SERVO5_FUNCTION=6` / Mount Yaw |
| Tilt / Pitch | Pixhawk `MAIN 6` | `SERVO6_FUNCTION=7` / Mount Pitch |

`MAIN 5`と`MAIN 6`を使う理由は、現在未使用であり、走行用の`MAIN 1`・`MAIN 3`と左右距離計用の`AUX 1`～`AUX 4`に競合しないためである。

## 3. 配線計画

### Pixhawk PWM端子

Pixhawk 6C MiniのMAIN/AUX出力は次の3端子である。

```text
S = PWM信号
+ = VDD_SERVO電源レール
- = GND
```

PWM信号は標準状態で3.3V。サーボが3.3V PWM信号を認識できるか、サーボの仕様または実機で確認する。確認前にPixhawkを開封してPWM信号電圧のハンダブリッジを変更しない。

### 信号線

```text
Pixhawk MAIN 5 / S → Panサーボ信号
Pixhawk MAIN 6 / S → Tiltサーボ信号
Pixhawk GND        → サーボ電源GNDと共通化
```

### 電源方針

現在のCC-02は、QuicRun WP-1060 ESCの内蔵BEC公称6V / 3Aが`MAIN 3`の赤線から`VDD_SERVO`へ入り、MAIN/AUXの共通サーボレールを給電している。Pixhawkの`POWER`端子からサーボ電源が供給されているわけではない。

サーボ型番確定後、次のどちらかを選ぶ。

#### A. 既存の6V / 3A BECを使う

次のすべてを満たす場合の候補とする。

- Pan・Tiltサーボが6Vに対応する。
- ステアリング、Pan、Tiltの同時停止電流とその他の負荷を合計しても、BECの3A定格に余裕がある。
- サーボ動作中にサーボレールの電圧低下、Pixhawk再起動、操舵サーボの瞬停が発生しない。

この場合は、サーボの3線コネクタを`MAIN 5`と`MAIN 6`へ接続する。

#### B. ジンバル用の別BECを使う

サーボの停止電流が不明、合計電流に余裕がない、または電圧低下が見られる場合の推奨方式とする。

```text
Pixhawk MAIN 5 / S ── Pan信号
Pixhawk MAIN 6 / S ── Tilt信号

別BEC + ───────── サーボ電源+
別BEC GND ─┬─────── サーボGND
            └─────── Pixhawk GND
```

別BECの`+`はジンバルサーボだけへ供給し、ESC BECが接続された`VDD_SERVO`の`+`と並列接続しない。異なるBECのプラス出力同士を直結しない。GNDは必ず共通化する。

## 4. ArduPilotパラメータ案

サーボと機構の仕様を確定し、現在パラメータを保存してから次を設定する。

```text
MNT1_TYPE       = 1    # Servo、変更後に再起動
SERVO5_FUNCTION = 6    # Mount Yaw / Pan
SERVO6_FUNCTION = 7    # Mount Pitch / Tilt
```

現在の保存値は次のとおり。

```text
MNT1_TYPE       = 0
SERVO5_FUNCTION = 0
SERVO5_MIN      = 1100
SERVO5_TRIM     = 1500
SERVO5_MAX      = 1900
SERVO6_FUNCTION = 0
SERVO6_MIN      = 1100
SERVO6_TRIM     = 1500
SERVO6_MAX      = 1900
```

### 初期可動範囲

`SERVO5_MIN/MAX`、`SERVO6_MIN/MAX`、`MNT1_YAW_MIN/MAX`、`MNT1_PITCH_MIN/MAX`は、実機のサーボと機構に合わせて決定する。最初から保存値の1100～1900 µs全域でリンクを動かさない。

初回はサーボホーンと機構を切り離し、1500 µs付近の中立を確認する。リンク接続後は狭い範囲から広げ、サーボのロック、異音、発熱、ケーブル張力が発生する手前に上下限を設定する。

## 5. 機構設計の条件

- OV5647カメラ基板、レンズ、CSIリボンケーブルに荷重を掛けない。
- CSIリボンケーブルにサービスループを設け、ジンバル固定側で引っ張り止めする。
- CSIケーブルは連続回転に対応しないため、Pan軸を360°回転としない。
- 初期Pan範囲は例えば中立から左右各45°程度の狭い範囲で確認し、ケーブル余長と機構干渉を見て決定する。
- Tilt軸も、車体、タイヤ、ジンバル枠、カメラケーブルへ接触しない範囲とする。
- 振動対策としてカメラ取付部に柔軟性のある防振材を検討するが、機構が揺れ続けるほど柔らかくしない。

## 6. 導入前に確定する項目

| 項目 | 状態 | 確認内容 |
| --- | --- | --- |
| Panサーボ型番 | 未確定 | 定格電圧、停止電流、角度、PWM周期、3.3V信号対応 |
| Tiltサーボ型番 | 未確定 | 定格電圧、停止電流、角度、PWM周期、3.3V信号対応 |
| ジンバル機構 | 未設計 | 質量、重心、サーボトルク、ケーブル処理、取付強度 |
| 電源方式 | 未決定 | 既存6V / 3A BECの余裕、または別BECの定格 |
| Pan/Tilt可動範囲 | 未確定 | 機構干渉とCSIケーブル張力が発生しない範囲 |
| 操作方法 | 候補 | Mission Planner Gimbal Control、RCチャンネル、MAVLink Mount指令 |

## 7. 実装と段階試験

### 準備

1. 現在のArduPilot全パラメータを日付付きファイルへ保存する。
2. サーボの型番と仕様書を記録する。
3. BECの無負荷電圧とサーボレール電圧をテスターで測る。
4. Roverの駆動輪を浮かせ、モータが予期せず回転しても移動しない状態にする。可能なら初回は駆動用モータ電源を物理的に切り離す。

### 無負荷サーボ試験

1. サーボホーンをジンバル機構から外す。
2. Panサーボだけを接続する。
3. `MNT1_TYPE=1`を設定してPixhawkを再起動する。
4. `SERVO5_FUNCTION=6`を設定し、中立と動作方向を確認する。
5. Tiltサーボを追加し、`SERVO6_FUNCTION=7`で同様に確認する。
6. 電圧低下、発熱、異音、ジッタを確認する。

### 機構接続試験

1. 1500 µs付近でサーボを中立にしてからホーンを固定する。
2. 狭いPWM範囲と角度範囲から試験する。
3. Mission PlannerからPanとTiltを個別に操作する。
4. 同時動作でBEC電圧とPixhawkの状態を確認する。
5. RTSP映像を表示し、実際の映像方向とジンバル指令が一致するか確認する。
6. DataFlashログの`RCOU.C5`、`RCOU.C6`と目視動作を併せて記録する。PWM出力だけでは、機構が正しく動いた証明にはならない。

### Rover統合試験

1. ステアリングを左右端まで操作しながらPan/Tiltを動かす。
2. スロットルを低速で動作させながら、映像切断、サーボの誤動作、PixhawkやPiの再起動がないか確認する。
3. 屋内ベンチ試験の完了後に、平坦で安全な場所で低速実走試験を行う。

## 8. 中止条件

次のいずれかが発生した場合は直ちに試験を中止する。

- サーボが機構端でロックする。
- サーボ、BEC、配線が異常発熱する。
- サーボレール電圧が大きく低下する。
- PixhawkまたはRaspberry Piが再起動する。
- ステアリングまたはESCが予期せず動作する。
- CSIケーブルが張る、折れる、ジンバル機構へ巻き込まれる。
- 映像が繰り返し停止する。

## 9. 復旧計画

ジンバルを取り外す場合は、電源を切ってサーボ配線を外し、保存したパラメータを基準に次を戻す。

```text
MNT1_TYPE       = 0
SERVO5_FUNCTION = 0
SERVO5_MIN      = 1100
SERVO5_TRIM     = 1500
SERVO5_MAX      = 1900
SERVO6_FUNCTION = 0
SERVO6_MIN      = 1100
SERVO6_TRIM     = 1500
SERVO6_MAX      = 1900
```

変更後にPixhawkを再起動し、ステアリング、スロットル、MAVLink、RTSP映像を再確認する。
