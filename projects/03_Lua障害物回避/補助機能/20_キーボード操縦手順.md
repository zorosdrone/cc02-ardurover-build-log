# Rover SITLをWASDキーボードで操縦する手順

更新日: 2026-06-22

## 1. 目的

Mission Plannerを表示・監視用として使用しながら、別のPythonスクリプトからRover SITLへRC入力を送り、PCキーボードのWASDで操縦する。

操作は`RC_CHANNELS_OVERRIDE`を20 Hzで送信して行う。

## 2. 操作キー

| キー | 動作 |
|---|---|
| `W` | 前進 |
| `S` | 後退 |
| `A` | 左旋回 |
| `D` | 右旋回 |
| `Space` | ステアリング・スロットルを中立へ戻す |
| `Esc` / `Q` | 中立を送信して終了 |

ウィンドウがフォーカスを失った場合も、自動的に中立値を送信する。

## 3. 構成

```text
Rover SITL
   ↓
MAVProxy
   ├─ UDP 14550 → Mission Planner
   └─ UDP 14551 → keyboard_rover.py
```

Mission Plannerとキーボードスクリプトは、異なるUDP出力ポートを使用する。

## 4. 必要ファイル

```text
keyboard_rover.py
```

必要なPythonパッケージ:

```bash
python3 -m pip install pymavlink pygame
```

## 5. MAVProxyの出力確認

MAVProxyコンソールで実行する。

```text
output
```

表示例:

```text
0: 127.0.0.1:14550
1: 127.0.0.1:14551
```

Mission Plannerは`14550`へ接続し、キーボードスクリプトは`14551`を使用する。

14551がない場合はMAVProxyで追加する。

```text
output add 127.0.0.1:14551
```

## 6. Roverを操縦可能な状態にする

障害物回避を確認する場合は、`MANUAL`ではなく`ACRO`を使用する。

```text
mode acro
arm throttle
```

障害物回避試験中は、次の設定を維持する。

```text
PRX1_TYPE    = 4
AVOID_ENABLE = 7
OA_TYPE      = 0
```

## 7. スクリプトを実行

```bash
python3 keyboard_rover.py
```

標準接続先:

```text
udpin:0.0.0.0:14551
```

接続先を変更する場合:

```bash
python3 keyboard_rover.py --connect udpin:0.0.0.0:14552
```

## 8. 操作量の調整

標準値:

```text
前進       RC3 = 1550
後退       RC3 = 1450
左旋回     RC1 = 1250
右旋回     RC1 = 1750
中立       RC1 = 1500
           RC3 = 1500
```

低速・小舵角で試す場合:

```bash
python3 keyboard_rover.py --throttle 30 --steering 180
```

| オプション | 意味 |
|---|---|
| `--throttle` | 1500からのスロットル増減量 |
| `--steering` | 1500からのステアリング増減量 |
| `--connect` | MAVLink接続先 |

## 9. 停止手順

通常終了:

```text
Space
Esc
```

スクリプト終了時には中立値を複数回送信する。

その後、MAVProxyでDisarmする。

```text
disarm
```

## 10. 障害物回避試験での使用

前方LiDARとSimple Object Avoidanceを使う場合:

```text
Wキーで前進
   ↓
前方Rangefinderが障害物を検出
   ↓
PRX1_TYPE=4でProximityへ変換
   ↓
Simple Object Avoidanceが減速・停止
```

距離確認:

```text
Mission Planner
→ Ctrl + F
→ MAVLink Inspector
→ DISTANCE_SENSOR
→ current_distance
```

速度確認:

```text
Mission Planner
→ Tuning
→ groundspeed
```

## 11. 注意事項

- 最初は低速設定で試験する
- `MANUAL`ではSimple Object Avoidanceが機能しない
- Mission Plannerのジョイスティック設定と同時使用しない
- MAVProxyの`rc`コマンドによる固定入力を残さない
- 操作不能時は`Space`を押し、スクリプトを終了してDisarmする
- 実機へ接続する場合は、タイヤを浮かせた状態で確認してから走行試験へ進む
