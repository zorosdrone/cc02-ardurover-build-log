# 02 チューニング

ArduRoverの低速走行、旋回、障害物停止、フェイルセーフ、QuikTuneの記録を管理する。

## 主な資料

- [ArduRoverチューニング手順](08_ArduRoverチューニング手順.md)
- [チューニングログ](09_チューニングログ.md)

## 成果物

- `params/tuned/` - チューニング前後と通常運用版のパラメータ
- `logs/test_runs/` - 試験ごとのMarkdown記録
- `logs/accepted/` - 再解析価値が高いGit LFS管理ログ
- `videos/` - チューニングと障害物回避の確認動画
- `photos/field_tests/` - 屋外試験時の機体と試験環境
