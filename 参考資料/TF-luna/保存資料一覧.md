# TF-Luna 保存資料一覧

Benewake TF-Luna LiDAR / RangeFinderに関する保存資料です。

## 保管方針

- 公式PDFや付属ツール本体はGit管理しない。
- Git管理するのは、この資料一覧のみ。
- 配線、UART/I2Cモード、Pixhawk接続、ArduPilot設定の根拠として使う。

## 今回の配線根拠

Pixhawk 6C Mini `TELEM2`側:

- Holybro公式 `Pixhawk 6C Mini Ports`
- `TELEM2`: `Pin1 VCC`, `Pin2 UART5_TX`, `Pin3 UART5_RX`, `Pin4 UART5_CTS`, `Pin5 UART5_RTS`, `Pin6 GND`

TF-Luna側:

- Benewake公式 `TF-Luna User Manual.pdf`
- Benewake公式 `Application of TF-Luna UART in Pixhawk.pdf`
- UART時: `+5V`, `RXD`, `TXD`, `GND`
- Configuration InputをGNDへ落とすとI2Cモードになるため、UART運用では未接続にする。
- `TF-Luna User Manual.pdf` の `6.1 Description about Line Sequence and Connection` / `Table 6` は、ピン番号と機能の根拠。線色はこの表では定義されていない。
- 線色はBenewakeのQuick Implementation系資料に `1=Red/+5V`, `2=White/RXD-SDA`, `3=Green/TXD-SCL`, `4=Black/GND` の表記があるが、実作業ではピン番号と導通確認を優先する。

ArduPilot設定:

- ArduPilot公式 RangeFinder / Benewake TF-Luna関連資料
- UART RangeFinderとして `SERIALx_PROTOCOL=9`
- `TELEM2`を使う場合はPixhawk 6C Mini上で `SERIAL2` を設定対象にする。
